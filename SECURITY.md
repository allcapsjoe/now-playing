# Security policy

## Supported versions

Until the first stable release, only the latest published version receives
security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting (**Security → Report a
vulnerability** on this repository) rather than a public issue. Include the
affected version, reproduction steps and impact. Don't include private
listening history or credentials.

Now Playing is designed to run without elevated rights, network access,
account credentials or saved track history.
